# trabajo-integrador
Trabajo Integrador: Super Mario Bros

Integrantes: Alexis Gómez, Mateo González, Magali Medina.

- Qué archivos tiene
+ index.html: la página.
+ estilo.css: los colores y el diseño.
+ js/script.js: el botón "Ver más".
+ js/contador_formulario.js: el contador de monedas y el formulario.
+ imagenes/: las fotos de la galería.

- Dónde usamos cada cosa
+ HTML: lo usamos para armar la página. Tiene el encabezado (header), el menú (nav), las secciones (section), el contenido principal (main) y el pie de página (footer). También hay listas, imágenes, links y un formulario.
+ CSS: lo usamos para que la página se vea mejor. Le pusimos colores, cambiamos las letras, los espacios y el aspecto del menú.
+ Flexbox: lo usamos en el menú para que los links queden uno al lado del otro.
+ Grid: lo usamos en la galería para que las fotos queden en columnas.
+ Media Queries: están al final del CSS. Cuando la pantalla es chica (como un celu), el menú pasa a ser una columna y la galería pasa a 2 columnas.
+ JavaScript: lo usamos para que la página haga cosas cuando tocás algo:
   - Botón "Ver más": muestra o esconde un párrafo en la parte de Historia.
   - Contador de monedas: cada vez que tocás el botón suma una moneda. También hay un botón para volver a 0.
   - Formulario de contacto: avisa si dejás un campo vacío o si el mail está mal. Si hay errores, no se envía.
